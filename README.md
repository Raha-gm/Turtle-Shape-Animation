# Turtle Shape Animation 🐢

A simple animation project created using Python's Turtle graphics module.

This project uses object-oriented programming to create colorful turtle objects that draw rotating geometric shapes.

## Features

- Object-oriented programming
- Custom Turtle class
- Circle drawing
- Square drawing
- Rotating geometric patterns
- Colorful animations

## Technologies Used

- Python
- Turtle Graphics
- Object-Oriented Programming (OOP)

## Project Structure

```text
Turtle-Shape-Animation/
├── main.py
├── ball.py
└── README.md
```

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

```bash
python main.py
```

## Requirements

No external libraries are required. This project uses Python's built-in Turtle module.

## Preview

Run the program to see the animated geometric patterns.

Click on the Turtle window to close it.
